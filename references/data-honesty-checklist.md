# 数据诚实性检查

> 配套 skill：website-qa-gates ｜ references ｜ 2026-10-06（VIZ7 新增，追加式补入）
> 与《vertciti 设计哲学 v1》"可验证的城市"＋🟢🟡⚪诚实材质同构：图表是数字的放大器，先审诚实再审美观。

## H1 · 材质标注

- 做什么：图表数据必须带诚实材质标注——🟢真实（已验证）/ 🟡原型（演示数据）/ ⚪规划（目标值）。
- PASS 标准：图题或图注旁材质徽章在位；🟡 数据图注明示"演示数据"；禁🟢包装🟡、禁⚪藏🟡（G6 三条红线同标准）。

## H2 · 口径小字

- 做什么：图内任何大字数字必须配口径小字（统计口径/时间范围/样本说明）。
- PASS 标准：大字数字旁有小字说明（如"截至 2026-09-30""n=309""演示数据"）；无来源形容词大字（scorecard visual_craft 同标准）。

## H3 · 轴与比例诚实

- 做什么：与 E2 联动——轴起点、截断、双轴必须诚实。
- PASS 标准：y 轴默认从 0 起；截断轴必须在图上显式标注断裂符号＋文字说明；双轴图必须在图注写明两侧单位与量级；禁 3D 饼图（面积/角度双重误导）。

## H4 · 选择性呈现审查

- 做什么：查"只画好看的时间段""只标有利的系列"类选择性呈现。
- 方法：审读数据时间范围与数据源全量范围是否一致；系列缺失需说明。
- PASS 标准：时间范围与数据源一致；被省略的系列/时间段在图注说明原因；与数据-room 源文件交叉核对零漂移。

## H5 · 预估与实测区分

- 做什么：预估/预测线必须与实测线视觉区分（虚线/浅色/标注"预测"）。
- PASS 标准：预测段用虚线或不同明度＋图例明确标注"预测"；禁实线预测冒充实测。

## 证据要求

- H1–H5：贴图截图（材质徽章/口径小字/轴标注在位）＋数据源交叉核对记录。
- 任一 FAIL 按 A-011 三段制输出（结论＋证据＋怎么修），停发。
