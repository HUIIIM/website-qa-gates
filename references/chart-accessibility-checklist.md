# 图表无障碍检查点

> 配套 skill：website-qa-gates ｜ references ｜ 2026-10-06（VIZ7 新增，追加式补入）
> 与 SKILL.md VIZ9 门禁同构：本文件是 VIZ9 的执行方法清单。

## A1 · 色盲安全

- 做什么：图表配色通过 deuteranopia（红绿色盲）/ protanopia（红色盲）模拟检查。
- 方法：取图表配色色板→色盲模拟器（或脚本矩阵变换）→检查关键系列在模拟下仍可区分。
- PASS 标准：红绿对比禁用；相邻系列在两种模拟下色相/明度差可区分；失败时改用"色相＋明度＋线型/纹理"三重编码。

## A2 · 文字对比度 ≥4.5:1

- 做什么：图表内所有文字（坐标轴 label、图例、数据标签、tooltip）与背景对比度取色实测。
- PASS 标准：正文/标签 ≥4.5:1；大号数据字（≥18pt）≥3:1；未达标即 FAIL。

## A3 · 文字替代（数据可读性）

- 做什么：每张图表必须有文字版数据摘要——aria-label/alt 描述或 accompanying data table。
- PASS 标准：读屏器能读出图表结论（不是"图片"二字）；数据表与图表数字一一对应；图表结论句用完整句子（例："S4 账单审计进行中，占三项审计中的第二项"）。

## A4 · 键盘可达

- 做什么：交互式图表（可 hover/可点击系列）必须键盘可达。
- PASS 标准：Tab 能进入图表区域；方向键/回车可切换系列并读出 tooltip 内容；焦点环可见（A++ 硬扫第 4 项同标准）；纯展示图表可 aria-hidden。

## A5 · 减少动态效果

- 做什么：图表入场动画在 `prefers-reduced-motion: reduce` 下禁用。
- PASS 标准：ECharts `animation: false` 在 reduce 媒体查询下生效；静态帧信息完整（M1/M4 同标准）。

## 证据要求

- A1：贴模拟截图（正常 vs 两种色盲）＋区分结论。
- A2：取色器实测值列表。
- A3：读屏朗读记录或数据表截图。
- A4/A5：真浏览器走查记录；走不了写"未验证"，不许推测硬过。
- 真实拦截/放行记录按 VIZ9 记入发布记录（日期/页面/拦截项/处置）。
