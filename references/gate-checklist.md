> 配套 skill：website-qa-gates ｜ 版本 v1.2 ｜ 2026-10-06（新增 G14 "AI 初筛＋人工终审"双轮制；G13 操作细则保留）
> 口径来源：本团队网站治理体系（G1–G9）、动效标杆深研（M1–M4）、A++ 审美标准。用自己的话转写。

**总规则**：每批发布必跑全部十四项门禁＋五项硬扫，任一 FAIL 停发，返工复验。质检组抽查留痕。

## G1–G9 发布门禁

### G1 · data-room 敏感信息扫描

- 做什么：扫描发布包里的资料室文件，查"绝密"字样、未来日期章、私钥、token、密钥等不应公开的内容。
- 命令：`bash ~/workspace/vertcity/security-watch/data-room-gate.sh`
- PASS 标准：零 FAIL 项。命中公开联系邮箱等为 WARN——可发布，但须人工复核确认是应公开项。

### G2 · 触控目标 ≥44×44

- 做什么：390px 视口下量取所有可见可交互元素（链接/按钮/输入框等）的触控尺寸。
- 命令：`bash ~/workspace/vertcity/deliverables/qa-gates/touch-target-check.sh [URL]`
- PASS 标准：exit 0 且输出 `RESULT: [PASS]`；全部可见可交互元素 ≥44×44。纯文本内联链接豁免，单独列备查。
- 基线：2026-09-28 实测 748 个元素全 PASS。新路由/新组件上线后必须加测，不许沿用旧基线。

### G3 · 390px 零横向截断

- 做什么：22 个路由 × 中英双语 @390px，检查有无元素被横向裁剪。注意 `overflow-x:hidden` 会静默裁剪，常规检测失明，必须用专用脚本。
- 命令：`bash ~/workspace/vertcity/deliverables/qa-gates/overflow-gate.sh [SITE_ROOT]`
- PASS 标准：exit 0 且输出 `OVERFLOW GATE: PASS`。

### G4 · 体积预算

- 做什么：卡首屏体积与核心性能指标，防止变更把页面养胖。
- 命令：`bash ~/workspace/vertcity/deliverables/qa-gates/size-gate.sh`
- PASS 标准：移动端首屏 ≤1.5MB；LCP ≤2.5s、CLS ≤0.1、INP ≤200ms（真机 Lighthouse）。

### G5 · 中英镜像一致性

- 做什么：变更内容在中英双版同时落地，结构、数据、来源标注一一对应，不许单语悬空。
- 方法：中英双版逐项比对（数字/文案/链接/标注）。
- PASS 标准：双版断言一一对应；英文版无全角标点；双语块排布符合规范（当前语言在上字大，另一语言在下字小）。

### G6 · 题材说明书机械项

- 做什么：核对变更涉及的题材/数字/状态表述与题材说明书一致——数字联动处改一处必改全处，状态材质（🟢真实/🟡原型/⚪规划）与内容相符。
- 方法：源码 grep 数字一致性；材质三条红线检查（禁🟢包装🟡、禁⚪藏🟡、一卡一种材质）。
- PASS 标准：联动数字零漂移；材质与内容相符。

### G7 · CSP 内联脚本 hash round-trip

- 做什么：页面内联脚本改了必须同步重算 `script-src` hash，否则浏览器拦截致白屏。round-trip＝重算当前内联脚本 hash，与部署配置里的 hash 逐个比对。
- 方法：提取内联 `<script>` 内容 → sha256 → base64 → 与 `vercel.json` 内 hash 比对。
- PASS 标准：全部 hash 一一对应，无多无少。

### G8 · 生产可达性

- 做什么：READY ≠ 可访问。部署后必须真实请求生产 URL。
- 命令：`curl -s -o /dev/null -w "%{http_code}" https://vertciti.com/`（及本次变更涉及的路由）
- PASS 标准：HTTP 200。

### G9 · 真机渲染复验

- 做什么：真浏览器（生产 CSP 下）渲染桌面 1440px＋移动 390px，确认页面非空、无内联脚本拦截报错、无横滚、布局完整。
- 方法：真浏览器人工目检＋截图留痕。headless Chromium（`/opt/meta-chromium/chrome`）可用于预检，但最终以真浏览器为准。
- PASS 标准：`#app` 非空；控制台零错误零警告；390px 页脚逐项检查通过（文字对比度、按钮可读性、法律链接胶囊可点）。

### G14 · AI 初筛＋人工终审双轮制（N6，2026-10-06 并入）

- 做什么：机器先全量扫描标可疑项，终审人只看标红项逐项终审＋未标红项随机抽查 ≥10%，压缩专家时间但终审权永不下放。
- 方法：
  1. **轮一 AI 初筛**：全量扫描交付物，按五类输出《可疑项清单》（文件＋位置＋疑点＋初筛证据）：
     绝密泄露（data-room 敏感扫描）／品牌违规（`Vertcity` 残留、旧头像/简介、作废产品线口径）／
     对比度（390px 页脚胶囊、图表文字 ≥4.5:1）／错字串页（中英双版文案）／首帧有效（视频第 1 帧禁黑屏/纯色）。
  2. **轮二 人工终审**：终审人对标红项逐项给结论（通过/打回＋理由）；未标红项随机抽查 ≥10%。
- PASS 标准：终审结论已署名留痕（格式 `终审：{通过/打回}｜终审人：{agent/人}｜时间：{ISO}｜依据：{条款}`）；
  审计报告含"初筛命中数 / 终审确认数 / 误报数"三行。
- 铁律：初筛永不代替终审；无署名＝未终审；H4 记账中 G14 的终审项按诚实原则记（未终审＝waived，不许用初筛 PASS 代替）。

## M1–M4 动效专项门禁

### M1 · 关动效静态帧完整性（static_frame_integrity）

- 做什么：真浏览器注入 `*{animation:none!important;transition:none!important}` 后截首屏（1440＋390），人工目检。
- PASS 标准：关掉动效后首屏依然是"一张成立的设计"——标题层级清晰、CTA 可见、无元素重叠错位。
- 失败含义：动效在遮丑——打回动效方案，先修静态构图。

### M2 · 降速帧率稳定（throttled_fps_stable）

- 做什么：DevTools CPU 4× 节流＋Fast 3G 下滚动全站，用 FPS meter 记录；关键动效段逐帧抽查。
- PASS 标准：全程 ≥55fps，无长任务阻塞滚动。
- 备注：无动效的纯静态变更记"不适用"，不扣分。

### M3 · 转场编排审计（transition_choreography）

- 做什么：列出本次变更涉及的全部状态转场（页面切换/tab/弹窗/章节衔接），逐个分类：硬切 / 移动（位移/缩放/透明度编排）/ 无转场。
- PASS 标准：硬切数量＝0（`prefers-reduced-motion` 下的有意降级除外）；每个"移动"转场有明确意义（引导视线/保持上下文），不是为动而动。
- 验收物：`transition-audit.md`（转场清单＋分类＋意义说明），随变更单归档。无新增转场的变更记"无新增转场"，仍需留一行记录。

### M4 · 减少动态效果三级验收（reduced_motion_respected）

- 做什么：在系统开启"减少动态效果"后复验。不是"写了媒体查询"就行，要三级：
  1. 所有动效有静态替代——替代不是 `display:none` 藏内容；
  2. 替代后信息完整——M1 的静态帧检查在 reduce 模式下重跑一遍；
  3. 键盘/读屏用户不受影响。
- PASS 标准：三级全部通过。不达标＝动效方案打回。

## A++ 审美硬扫（五项）

变更涉及视觉时必扫：

1. **字阶命中**：字号全部命中字阶表（Display 40 / H1 32 / H2 24 / H3 20 / Body 16 / Small 14 / Caption 12），禁 13/15/17/19px。源码 grep 非字阶字号＝0。
2. **8pt 间距**：间距值全部命中合法 scale（4/8/12/16/20/24/32/40/48/56/64/80/96/120），除 4px 外须为 8 的倍数。
3. **按钮五态**：新增/改动的按钮具备默认/悬停/按下/禁用/加载中五态样式；一屏只许一个主要按钮；直角统一。
4. **焦点环全覆盖**：所有可聚焦元素 `:focus-visible` 可见（2px teal＋2px 偏移）；键盘 Tab 全程可达。
5. **count-up 归零**：源码搜 `countUp|animate-number`＝0。数字展示用静态值，永禁数字滚动动画。

## G13 · 模糊词翻译门禁（MV196，Oil UI 原则 2）

- 做什么：视觉评审意见里的「高级 / 简洁 / 大气 / 有质感 / 更顺眼 / 精致 / 国际范」类模糊词，必须翻译成**字体 / 留白 / 色彩面积 / 字阶 / 对齐 / 动效**等具体决定，否则该条意见打回，不得进入变更单。
- 方法：每条视觉变更单附"模糊词翻译表"，三列缺一不可：

| 原词（评审原话） | 具体决定（可执行的样式/数值变更） | 落点（选择器/文件行） |
|---|---|---|
| 例："hero 更大气" | Display 字号 40px→clamp 上限 48px；眉题字距 .12em→.16em；首屏留白 96px→120px | `.hero-title` / index.html L210 |
| 例："卡片更有质感" | 卡片边框 1px→1.5px 实线；阴影 `0 8px 24px rgba(0,0,0,.08)`；内边距 20px→24px（8pt 网格） | `.card` / index.html L480 |

- 常见模糊词→具体决定映射（起草翻译表时参考，不许直接套用不经验证）：

| 模糊词 | 必须翻译成的决定维度 | 不合格的写法 |
|---|---|---|
| 高级 | 字阶差拉大 / 色彩面积比（强调色 ≤10%）/ 留白增加一档 | "整体调高级一点" |
| 简洁 | 删元素（列出删哪几个）/ 字阶种类 ≤3 / eyebrow 计数复核 | "页面做简洁些" |
| 大气 | Display 字号上调 / 区块纵向节奏 96px→120px / 字距放宽 | "感觉不够大气" |
| 有质感 | 边框/阴影/材质三选一具体数值 / 禁纯色大色块 | "质感再强一点" |
| 更顺眼 | 必须拆成对齐/对比度/节奏中的至少一项具体改动 | "看着不顺眼，调调" |

- PASS 标准：变更单中出现的每个模糊词都有翻译表对应行，且"具体决定"列可被源码 grep 验证（如字号数值、选择器存在）；翻译表缺失或"具体决定"不可验证＝本门禁 FAIL，打回评审意见。
- 豁免：纯主观感受句（如"我喜欢这个"）不进评审记录，不触发本门禁——但也不得作为任何变更依据。

## VIZ9 · 图表可访问性门禁（chart_a11y）

- 做什么：数据图表（SVG 数据图 / canvas 图表库 / 信息图）三项全过才可发布：
  1. **色盲安全**：配色通过 deuteranopia（绿色盲）/ protanopia（红色盲）模拟检查——红绿对比禁用，色相编码必须有形状/纹理/标注双保险。
     方法：截图 → deuteranopia/protanopia 模拟器（或 CSS 滤镜近似）目检；仍能区分各系列＝PASS。
  2. **对比度**：图表内所有文字（轴标签/图例/数据标签）与背景对比度 ≥ 4.5:1；纯图形（无文本含义）≥ 3:1。
     方法：取色（真浏览器拾色或源码 hex）→ 计算 WCAG 对比度。
  3. **文字替代**：每张数据图表必须有文字版数据摘要——`alt`/`aria-label` 概要 ＋ 随附数据表（`<table>` 或 data-room 链接），只用颜色讲故事的图表即 FAIL。
- PASS 标准：三项全过。装饰性 SVG（`aria-hidden="true"`）免检，但必须真正隐藏（非"装饰"却无 aria-hidden＝条件通过，建议修复）。
- FAIL 即停发，修到：换配色＋补数据表后重验。

## VIZ24 · G12 动效性能预算门禁（motion_perf_budget）

- 做什么：发布前对动效做性能预算检查：
  1. **白名单属性**：动效只允许 `transform` / `opacity`。其他属性（`height/width/left/top/filter:blur` 等）参与动效即 FAIL。
     方法：`grep` keyframes/transition/animation 属性 → 逐条核对白名单。
  2. **blur 限面积**：`backdrop-filter` / `filter: blur` 若参与动效，其影响面积 ≤ 视口 20%。静态 blur（不随动画变化）免此项。
     方法：定位动效 blur 元素 → 真浏览器量元素面积占比；无真浏览器则记"未验证"。
  3. **LCP 预算**：动效不得使 LCP 增加 > 300ms（staging 开/关动效各测一次，取差值）。
  4. **禁粒子背景**：全屏粒子 / canvas 背景动效一律 FAIL（源码 `grep particle|<canvas`＝0，且目检无全屏动态背景）。
- PASS 标准：四项全过。任一 FAIL 即停发。
- 既有站点基线（2026-10-06 源码级扫描，index.html）：particle 0 / canvas 0 / keyframes 4（`dolly/transform`,`draw/stroke-dashoffset`,`stamp/transform+opacity`,`ignite/height+opacity`）/ `prefers-reduced-motion` 3 处；`draw`/`ignite` 含非白名单属性——按 G12 口径记为既有问题，引用本台账，新变更不得新增非白名单动效。
